## 🚀 Fonctionnalités Majeures du Projet
* **Authentification avec Rôles Strictes** : Comptes Enseignant et Gestionnaire distincts.
* **Panneau d'Aiguillage Sécurisé (`/portal`)** : Interface commune après connexion distribuant les accès aux modules.
* **Gestion d'Éligibilité (Erreur 403 Personnalisée)** : Blocage immédiat si l'enseignant tente de voir les paiements ou si le gestionnaire tente de modifier les notes.
* **Modules Complets** : Gestion des Classes, Inscriptions des Élèves, Saisie des Notes par trimestre, et Suivi des Paiements.
